# Игровой архив — HTML-версия

Тёмная личная библиотека настольных ролевых игр. Работает без ChatGPT, сервера, регистрации, CDN и ключей доступа. Все зависимости включены в index.html. Исходники находятся в src; сборка уже выполнена.

## Открыть на компьютере

Откройте index.html двойным щелчком. Добавьте систему. Изменения сохраняются автоматически в IndexedDB этого браузера. Для переноса используйте «Данные» → «Экспорт JSON» / «Импорт JSON». При открытии через file:// начальные данные из соседнего archive.json не загружаются автоматически: импортируйте файл кнопкой.

## Разместить на GitHub Pages

1. Создайте репозиторий GitHub.
2. Загрузите содержимое этой папки в корень репозитория. Для работы сайта достаточно index.html, archive.json и .nojekyll. Не загружайте сам ZIP вместо его содержимого.
3. Откройте Settings → Pages. Выберите Deploy from a branch, ветку main, папку / (root), нажмите Save.
4. После публикации откройте адрес, который GitHub покажет в Pages.

Сборка npm и GitHub Actions для публикации не нужны. Названия пунктов интерфейса GitHub могут изменяться.

## Как обновлять данные в репозитории

1. Откройте приложение и добавьте или измените данные. Они сразу сохраняются в текущем браузере.
2. В левом нижнем углу откройте «Данные» → «Экспорт JSON». Скачается archive.json со всеми системами, дополнениями, сессиями и встроенными обложками.
3. Загрузите новый archive.json в корень репозитория, заменив старый файл. Подтвердите Commit changes.
4. После обновления GitHub Pages на другом устройстве откройте сайт. При первом запуске он загрузит archive.json. Если локальный архив уже есть, нажмите «Загрузить с GitHub» и подтвердите замену.

Автоматической записи в GitHub и слияния правок нет. Локальные изменения имеют приоритет и никогда не заменяются файлом с сайта без подтверждения. Перед импортом или загрузкой опубликованной версии экспортируйте текущую копию, если хотите сохранить обе версии. Если после обновления видна старая версия данных, подождите завершения публикации Pages и повторите загрузку.

Локальные данные не переносятся между разными браузерами, устройствами, доменами, копиями HTML-файла или режимом инкогнито. При очистке данных сайта браузер удаляет локальный архив — храните резервный archive.json.

Если репозиторий или сайт доступен публично, archive.json, включая заметки, даты и обложки, также будет доступен посетителям. Публикуйте только данные, которыми готовы делиться. Для хранения только на своём компьютере достаточно index.html и локального экспорта JSON.

## Возможности

- Библиотека систем с обложками и автоматическим Corebook.
- Дополнения по названиям; подсчёт материалов.
- Раздел «Я — игрок» без учёта владения материалами.
- Перенос системы из раздела игрока в библиотеку без потери сессий.
- Сессии: название, дата, время, часы, роль, кампания, заметки; редактирование и удаление.
- PNG-инфографика по системе и периоду: ◆ мастер, ● игрок.
- Обложки сжимаются до 800 пикселей и встраиваются в JSON. Поддержка JPEG, PNG, WebP.

Данные из прежнего облачного приложения автоматически не мигрируют. Облачные ссылки на обложки в импортируемом JSON не поддерживаются: такие картинки нужно загрузить заново.

## Изменить исходники

Установите Node.js, выполните npm install, затем npm run build. Получится новый самодостаточный index.html. npm test запускает проверки формата архива, импорта/экспорта и путей GitHub Pages.

Зависимости React и Lucide распространяются по лицензии MIT; их уведомления включены в bundle внутри index.html и приведены в THIRD_PARTY_NOTICES.txt.

Официальная инструкция GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Меню «Данные» находится внизу слева и содержит экспорт JSON, импорт JSON и загрузку с GitHub. Пункт «Инфографика · PNG» появляется на экране инфографики выбранной системы.
